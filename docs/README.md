# Worked examples

These pages walk through Beatles Bench one function at a time. Each walkthrough names the two or three files you need, gives the one `thinkthen` command that runs them, and shows how to read the answers. You can see why Jev gets a song right, and why it gets another song wrong or stays not sure.

Every command runs in its function's folder, `functions/<name>/`. It answers from a committed recording with `--replay recording`. It needs no key, no network, and no spend. Leave that option out, and the same command asks any ThinkThen-compatible server.
